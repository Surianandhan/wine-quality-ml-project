### Slide 4 · Class balancing — four schemes, one variable

**Its job:** Show that only the balancing changes — a controlled comparison.

**Say:** I compared four balancing schemes, holding everything else fixed so that the balancing is the only thing that changes. Class weights make mistakes on rare classes cost more during training. ### Slide 5 · Class balancing — results

**Its job:** The class-balancing result, and its honest cost.

**Say:** On the left, accuracy and macro-F1 for each scheme; on the right, recall per quality class. SMOTE oversampling gives the best macro-F1. ### Slide 8 · Route 2 — the fix, done properly

**Its job:** The main improvement: the fix, done without leakage.

**Say:** This is the main improvement, and it follows directly from the Review-1 diagnosis. The weighting formula is the paper's, but instead of a fixed temperature of 1, each training fold runs its own inner cross-validation to pick the temperature. The outer test fold never influences that choice, so this is a fair result. With exactly the same four learners, accuracy moves from 69.01 to 70.89 percent. And notice the last statistic: left to choose for itself, the inner CV picks a sharp temperature in 99 percent of folds. That is the data independently agreeing with my Review-1 diagnosis.

### Slide 11 · Feature importance — three views, checked against each other

**Its job:** Explain the importance methods before showing results.

**Say:** For feature importance I used three methods and checked them against each other. The primary one is permutation importance: shuffle a single lab measurement in the test fold — which breaks its link to quality — and see how much the score drops. Because it is computed on held-out data, it measures what the model really uses. Random Forest's built-in importance is shown for comparison only, because it is biased towards continuous features. The third view is direction: does a higher value mean better or worse wine. Finally I tested how many measurements are actually needed, with the selection done inside each fold to avoid leakage.
